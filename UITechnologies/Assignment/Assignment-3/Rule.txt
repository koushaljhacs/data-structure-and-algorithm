DESIGN REQUIREMENTS
===============================================================================

1. FORM STRUCTURE (Create in index.html):
   • Container div with class "container"
   • Header with title and subtitle
   • Form with id="registrationForm", action="/register", method="POST"
   • 5 sections with class "form-section":
      Section 1: Personal Information (Required fields)
      Section 2: Contact Information
      Section 3: Demographic Information
      Section 4: Professional Information
      Section 5: Terms and Conditions
   • Submit button
   • Footer with copyright

2. COLOR SPECIFICATIONS (USE COLOR NAMES ONLY):
   • Page background: lightgray
   • Main container background: white
   • Form section background: whitesmoke
   • Section title color: darkblue
   • Required field marker: red
   • Button background: blue
   • Button hover background: darkblue
   • Input border: gray
   • Input focus border: blue
   • Helper text color: gray
   • Footer text color: gray
   • Footer border: lightgray

3. LAYOUT SPECIFICATIONS:

   A. MAIN CONTAINER:
      • Width: 90% of screen
      • Maximum width: 800px
      • Center horizontally
      • Padding: 30px
      • Border radius: 10px
      • Box shadow: 0px 4px 8px gray

   B. HEADER:
      • Center aligned text
      • Bottom border: 2px solid blue
      • Title font size: 32px
      • Subtitle font size: 18px
      • Margin bottom: 30px
      • Padding bottom: 20px

   C. FORM SECTIONS:
      • Background: whitesmoke
      • Margin bottom: 25px
      • Padding: 20px
      • Border radius: 8px
      • Section title font size: 22px
      • Section title margin bottom: 15px

   D. FORM ROWS & INPUTS:
      • Form row margin bottom: 20px
      • Input group width: 100%
      • Labels: bold, black color, font size 16px
      • All inputs width: 100%
      • Input padding: 12px
      • Input border: 2px solid gray
      • Input border radius: 5px
      • Input font size: 16px
      • Textarea height: 100px, resize vertical only
      • Helper text font size: 14px, margin top: 5px

   E. BUTTON:
      • Center aligned
      • Background: blue, text: white
      • No border
      • Padding: 15px top/bottom, 40px left/right
      • Font size: 18px
      • Border radius: 5px
      • Cursor: pointer
      • Width: 100%, maximum width: 300px
      • Hover background: darkblue

   F. FOOTER:
      • Center aligned text
      • Top border: 1px solid lightgray
      • Margin top: 30px
      • Padding top: 20px
      • Font size: 14px

4. RESPONSIVE DESIGN (Mobile):
   • When screen width is 600px or less:
      - Container width: 95%
      - Container padding: 15px
      - Title font size: 24px
      - Form section padding: 15px

5. FORM CONTROLS REQUIRED:
   • Text input for Full Name (required)
   • Email input for Email (required)
   • Password input for Password (required)
   • Telephone input for Phone Number
   • Textarea for Address
   • Select dropdown for Gender (Male, Female, Other)
   • Date input for Date of Birth
   • Select dropdown for Country (India, USA, UK, Canada)
   • Select dropdown for Occupation (Student, Employed, etc.)
   • Select dropdown for Education (High School, Bachelor's, etc.)
   • Checkbox for Terms & Conditions (required)
   • Submit button
