How JavaScript Refers HTML elements?
1. JavaScript can refer HTML elements by using DOM hierarchy.
    Example: 01
        <!DOCTYPE html>
        <html>
            <head>
                <title>DOM Element</title>
                <script>
                    function bodyload() {
                        window.document.images[0].src = "../assets/laptop.png";
                        window.document.forms[0].elements[1].value = "Register";
                        window.document.forms[1].elements[1].value = "Login";
                    }
                </script>
            </head>
            <body onload="bodyload()">
                <img width="120" height="100" border="1">
                <div>
                    <form>
                        <h2>Register</h2>
                        User Name: <input type="text"> <input type="button">
                    </form>
                </div>
                <div>
                    <form>
                        <h2>Login</h2>
                        Email: <input type="email"> <input type="button">
                    </form>
                </div>
            </body>
        </html>

    - if we change the position of any element in page, then every time we have to update its position in code.
    - it is faster in rendering [generating output].


2. JavaScript can refer elements by using "name".
    Example: 01
        <!DOCTYPE html>
        <html>
            <head>
                <title>DOM Element</title>
                <script>
                    function bodyload() {
                        pic.src = "../assets/laptop.png";
                        frmRegister.btnRegister.value = "Register";
                        frmLogin.btnLogin.value = "Login";
                    }
                </script>
            </head>
            <body onload="bodyload()">
                <img width="120" height="100" border="1" name="pic">
                <div>
                    <form name="frmRegister">
                        <h2>Register</h2>
                        User Name: <input type="text" name="txtName"> <input type="button" name="btnRegister">
                    </form>
                </div>
                <div>
                    <form name="frmLogin">
                        <h2>Login</h2>
                        Email: <input type="email" name="txtEmail"> <input type="button" name="btnLogin">
                    </form>
                </div>
            </body>
        </html>

    - We can access any element directly by using its refernce name.
    - We can't access child elements directly.
    - We have to refer both parent and child hierarchy.

FAQ: DIFFERENCE BETWEEN innerHTML AND outerHTML

    innerHTML
        - Gets/sets ONLY the content INSIDE the element
        - Does NOT include the element's own tags
        - Modifies only children/content
        - Original element REMAINS in DOM

    outerHTML  
        - Gets/sets content INCLUDING the element itself
        - Includes element's opening tag + content + closing tag
        - Replaces ENTIRE element in DOM
        - Original element is REMOVED and REPLACED

    Example: 01
        <!DOCTYPE html>
        <html lang="en">
        <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>innerHTML vs outerHTML Examples</title>
        </head>
        <body>
            <h1>innerHTML vs outerHTML Demonstration</h1>

            <!-- Original HTML Structure -->
            <div id="container" class="box">
                <p>Hello World</p>
                <span>Text here</span>
            </div>

            <hr>

            <!-- innerHTML Examples -->
            <div id="innerHTML-example">
                <h2>innerHTML Operations:</h2>
                
                <button onclick="getInnerHTML()">Get innerHTML</button>
                <button onclick="setInnerHTML()">Set innerHTML</button>
                
                <div id="innerHTML-result"></div>
            </div>

            <hr>

            <!-- outerHTML Examples -->
            <div id="outerHTML-example">
                <h2>outerHTML Operations:</h2>
                
                <button onclick="getOuterHTML()">Get outerHTML</button>
                <button onclick="setOuterHTML()">Set outerHTML</button>
                
                <div id="outerHTML-result"></div>
            </div>

            <script>
                // innerHTML OPERATIONS
                
                function getInnerHTML() {
                    // GET innerHTML:
                    let inner = document.getElementById("container").innerHTML;
                    // Returns: "<p>Hello World</p><span>Text here</span>"
                    
                    document.getElementById("innerHTML-result").innerHTML = 
                        "<strong>GET innerHTML Result:</strong><br>" + 
                        "Returns: " + escapeHtml(inner);
                }

                function setInnerHTML() {
                    // SET innerHTML:  
                    document.getElementById("container").innerHTML = "<h1>New Content</h1>";
                    // Result: <div id="container" class="box"><h1>New Content</h1></div>
                    
                    document.getElementById("innerHTML-result").innerHTML = 
                        "<strong>SET innerHTML Result:</strong><br>" + 
                        "Now the container has: &lt;div id=\"container\" class=\"box\"&gt;&lt;h1&gt;New Content&lt;/h1&gt;&lt;/div&gt;";
                }

                // outerHTML OPERATIONS

                function getOuterHTML() {
                    // GET outerHTML:
                    let outer = document.getElementById("container").outerHTML;  
                    // Returns: '<div id="container" class="box"><p>Hello World</p><span>Text here</span></div>'
                    
                    document.getElementById("outerHTML-result").innerHTML = 
                        "<strong>GET outerHTML Result:</strong><br>" + 
                        "Returns: " + escapeHtml(outer);
                }

                function setOuterHTML() {
                    // SET outerHTML:
                    document.getElementById("container").outerHTML = "<section id='new-container'><h1>Complete Replacement</h1></section>";
                    // Result: <section><h1>Complete Replacement</h1></section>
                    
                    document.getElementById("outerHTML-result").innerHTML = 
                        "<strong>SET outerHTML Result:</strong><br>" + 
                        "Now the container is replaced with: &lt;section id=\"new-container\"&gt;&lt;h1&gt;Complete Replacement&lt;/h1&gt;&lt;/section&gt;";
                }

                // Helper function to escape HTML for display
                function escapeHtml(unsafe) {
                    return unsafe
                        .replace(/&/g, "&amp;")
                        .replace(/</g, "&lt;")
                        .replace(/>/g, "&gt;")
                        .replace(/"/g, "&quot;")
                        .replace(/'/g, "&#039;");
                }
            </script>
        </body>
        </html>

    COMPARISON TABLE:
        +------------------------------------------------------------------------------+
        | ASPECT         | innerHTML                    | outerHTML                    |
        |----------------|------------------------------|------------------------------|
        | SCOPE          | Content inside element       | Entire element + itself      |
        | GET OPERATION  | Returns children only        | Returns element + children   |
        | SET OPERATION  | Updates content only         | Replaces entire element      |
        | DOM IMPACT     | Element stays                | Element gets replaced        |
        | USE CASE       | Update content dynamically   | Change element type/structure|
        +----------------+------------------------------+------------------------------+

    WHEN TO USE:

        +---------------------------------+--------------------------------+
        | Use innerHTML WHEN:              | Use outerHTML WHEN:           |
        +----------------------------------+-------------------------------|
        | • Update text/content            | • Change element type         |
        | • Add/remove child elements      | • Replace entire structure    |
        | • Modify existing content        | • Transform element tag       |
        | • Keep element attributes        | • Complete element overhaul   |`
        +----------------------------------+-------------------------------+

FAQ: What is the difference between prompt() and an HTML <input>?"
ans: Prompt: It is blocking. The browser stops executing all other scripts until the user responds. It is also un-stylable.
     HTML Input: It is non-blocking. The user can interact with the rest of the page while the input is visible, and it can be fully styled with CSS.
     
FAQ: what is strict mode of JavaScript?
ans: Strict mode for JavaScript allows to reduce code in-consistency
     so that developers have to follow coding standards

        <script>
            "use strict";
            x = 10;                         --->    invalid : x is not defined
            document.write("x = " + x);
        </script>

        <script>
            "use script";
            var x = 10;                     --->    valid
            document.write("x = " + x);
        </script>
