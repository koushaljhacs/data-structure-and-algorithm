		---------------------------------------

			- OLTP databases are used for "running business" i.e. Live transaction (insert, update, delete, select)

what is data storage
--------------------
	- it is a location where we want to store data or information.
	- there are three methods to store data or information.
		1. Paper & Books (Before computers)
		2. Flatfiles or Text file (from computers)
		3. DBMS (software)					

		2. Flatfiles or Test File
		-------------------------
			- data can be stored in files with the help of operating system.
			
			Advantages:	
			-----------
				- it is computerized system
				- less man power
				- less cost

			Disadvantages:
			--------------
				- Data redundancy
				- Data inconsistency
				- Data retrieval
				- Data integrity
				- Data security
				- Data indexing

				Data redundancy
				----------------
					- storing same information in multiple files in computer

				Data inconsistency
				------------------
					- irregular data (different values)
					- it can occur when we have duplicate data i.e. no redundancy = no inconsistency

				Data retrieval
				--------------
					- retrieving the required data from flatfiles is highly complex because we need to develop an application program by using 
					  "c language" whereas retrieving the required data from database is very simple (easy) by using "sql-language".

				Data integrity
				--------------
					- to validating data is not possible in files whereas possible in database.

				Data security
				-------------
					- flatfiles are give poor security for data compare to database.

				Data indexing
				-------------
					- flatfiles are not supporting indexing mechanism whereas database supports indexing mechanism so that retrieving data is faster
					  than flatfiles.

what is DBMS
------------	
	- it is a software tools which is used to manage and maintain data or information in database.
	- by using DBMS software we can perform the following operations are:
		> create database memory
		> create tables
		> inserting data
		> updating data
		> selecting data
		> deleting data

	user <----------------------> DBMS software <-----------------------------> Database
				      ( interface )

Models of DBMS
--------------
	(1) Hierarchical Database Management System (HDBMS)
	    Ex:
		IMS software (Information Management System)
	
	(2) Network Database Management System (NDBMS)				NOTE: HDBMS, NDBMS models are outdated in realtime
	    Ex:
		IDBMS software (Integrated Database Management System)

	(3) Relational Database Management System (RDBMS)
		(3.1) Object Relational DBMS (ORDBMS)
		(3.2) Object Oriented DBMS (OODBMS)

		
		(3.1) Object Relational DBMS (ORDBMS)
		--------------------------------------
			- data can be stored in "table" format.
				table   : collection of row and columns
					  - rows or records or tuples 
					  - columns or fields or attributes 
		
				row     : group of columns
				columns : group of rows

			- completely depends on "SQL"
			  Ex:
				Oracle, MySQL, PostgreSQL, SQLServer....etc

		(3.2) Object Oriented DBMS (OODBMS)
		-----------------------------------
			- data can be stored in "object" format.
			- completely depends on "OOPS" concept.
			- not depends on "SQL" so that these databases are called as "No SQL" databases.
			  Ex:
				MongoDB, Cassandra.....etc.

	    4.2. TIMESTAMP:
	    ---------------
	    - It will store data and time information along with miliseconds.
			'DD-MON-YY/YYYY HH:MI:SS.MS'
			 1   1    2     1  1  1  4	---> 11 Bytes (Fixed Memory)
	    Ex:
		'27-DEC-2022 9:29:23.0000'



	5. RAW & LONG RAW DataTypes:
	----------------------------
	- Storing image / audio / video file into binary format (0101010010001).
	- these data types are also called as "Binary DataTypes" in oracle.
	    5.1. RAW maximum size	. 2000 Bytes (static)
	    5.2. LONG RAW Maximum size 	. 2 GB (Dynamic)


	6. LOW DataTypes:
	-----------------
	- Large Objects DataTypes.
	    6.1. CLOB
	    6.2. NCLOB
	    6.3. BLOB

	    6.1. CLOB:
	    ----------
	    - Character large object.
	    - will store non-unicode char's
	    - it is a dynamic datatype
	    - maximum size is 4 GB.

	    6.2. NCLOB:
	    -----------
	    - National Character Large Object
	    - Will store unicode character
	    - It is a dynamic datatype
	    - maximum size is 4 GB.

	    6.3. BLOB:
	    ----------
	    - Binary large object
	    - It is a dynamic datatype
	    - will store image / audio / video file inthe form of 010101010100010
	    - maximum size is 4 GB.

	NON-UNICODE CHARACTER:					UNICODE CHARACTER:				BINARY DATA:

	- LONG				- 	2 GB		LONG			- 	2 GB		BLOB		-	4 GB
	- CLOB				- 	4 GB		NCLOB			- 	4 GB

    ALTER:
    ------
    - to modify the structure of a table
    - is having four sub-commands
	1. ALTER-MODIFY
	---------------
	- to change datatype and also the size of datatype of a column
	syntax:
	    ALTER TABLE <TABLE NAME> MODIFY <COLUMN NAME> <NEW DATATYPE> [new size];

		SQL> ALTER TABLE STUDENT MODIFY SNAME VARCHAR2(5);
		Table altered.

		SQL> DESC STUDENT;
		 Name                                      Null?    Type
		 ----------------------------------------- -------- ----------------------------
		 STID                                               NUMBER(38)
		 SNAME                                              VARCHAR2(5)
		 SFEE						    NUMBER(6,2)


	2. ALTER-ADD:
	-------------
	- to add a new column to a table.
	syntax:
	    ALTER TABLE <TABLE NAME> ADD <NEW COLUMN NAME> <DATATYPE> [size]

		SQL> ALTER TABLE STUDENT ADD SADDRESS VARCHAR2(20);
		Table altered.

		SQL> DESC STUDENT;
 		 Name                                      Null?    Type
 		 ----------------------------------------- -------- ----------------------------
 		 STID                                               NUMBER(38)
		 SNAME                                              VARCHAR2(5)
 		 SFEE                                               NUMBER(6,2)
  		 SADDRESS                                           VARCHAR2(20)


	3. ALTER-RENAME:
	----------------
	- to change a column name.
	syntax:
	    ALTER TABLE <TABLE NAME> RENAME <COLUMN> <OLD COLUMN NAME> TO <NEW COLUMN NAME>

		SQL> ALTER TABLE STUDENT RENAME COLUMN SNAME TO STUDENTNAMES;
		Table altered.

		SQL> DESC STUDENT;
		 Name                                      Null?    Type
		 ----------------------------------------- -------- ----------------------------
		 STID                                               NUMBER(38)
		 STUDENTNAMES                                       VARCHAR2(5)
		 SFEE                                               NUMBER(6,2)
		 SADDRESS


	4. ALTER- DROP:
	---------------
	- to delete / drop a column from a table.
	syntax:
	    ALTER TABLE <TABLE NAME> DROP <COLUMN> <COLUMN NAME>;

		SQL> ALTER TABLE STUDENT DROP COLUMN SFEE;
		Table altered.

		SQL> DESC STUDENT;
		 Name                                      Null?    Type
		 ----------------------------------------- -------- ----------------------------
		 STID                                               NUMBER(38)
		 STUDENTNAMES                                       VARCHAR2(5)
		 SADDRESS

    TRUNCATE:
    ---------
    - to delete all rows (data) from a table at a time.
    - deleting rows but not columns (structure).
    - deleting rows (data) are permanent.
    - we cannot delete a specific row because truncate command is not allowed "WHERE" condition.
    syntax:
	TRUNCATE TABLE <TABLE NAME>;

	SQL> SELECT * FROM STUDENT;

      	STID STUDE SADDRESS
	---------- ----- --------------------
      	1001 SHANU KOLKATA

	SQL> TRUNCATE TABLE STUDENT;
	Table truncated.

	SQL> SELECT * FROM STUDENT;
	no rows selected

    New Features Of Oracle10g Enterprise Edition:
    ---------------------------------------------
    . RECYCLEBIN
    . FLASHBACK
    . PURGE

    RECYCLEBIN:
    -----------
    - It is system defined table.
    - It will store the information about deleted tables.
    - It is similar to windows recyclebin in computer.

    To view the deleted table in RECYCLEBIN:
    ----------------------------------------
    syntax:
	SELECT OBJECT_NAME, ORIGINAL_NAME FROM RECYCLEBIN;
	
	SQL> DESC RECYCLEBIN; [to view the structure of recycle bin]
	 Name                                      Null?    Type
	 ---------------------------------------- -------- ----------------------------
	 OBJECT_NAME                               NOT NULL VARCHAR2(128)
	 ORIGINAL_NAME                                      VARCHAR2(128)

	SQL> SELECT OBJECT_NAME, ORIGINAL_NAME FROM RECYCLEBIN;

	OBJECT_NAME
	--------------------------------------------------------------------------------
	ORIGINAL_NAME
	--------------------------------------------------------------------------------
	BIN$lYMTXFNZQOOR+UhnZ/bGvQ==$0
	STUDENT


    FLASHBACK:
    ----------
    - It is a DDL command.
    - to restore deleted tables from recyclebin to database memory.

    syntax:
	FLASHBACK TABLE <TABLE NAME> TO BEFORE DROP;

	SQL> FLASHBACK TABLE STUDENT TO BEFORE DROP;
	Flashback complete.

	SQL> SELECT OBJECT_NAME, ORIGINAL_NAME FROM RECYCLEBIN;
	no rows selected

	SQL> SELECT * FROM STUDENT;
        STID STUDE SADDRES
	---------- ----- --------------------
         1 A     HYD
         1 B     HYD

	SQL> SELECT * FROM TAB;
	TNAME
	--------------------------------------------------------------------------------
	TABTYPE        CLUSTERID
	------------- ----------
	STUDENT
	TABLE


    PURGE:
    ------
    - to delete a table from database / from recyclebin permanently.
    case-1: to delete a specific table from recyclebin:
    ---------------------------------------------------
    syntax:
	PURGE TABLE <TABLE NAME>;

	SQL> PURGE TABLE TEST1;
	Table purged.

	SQL> SELECT OBJECT_NAME, ORIGINAL_NAME FROM RECYCLEBIN;
	OBJECT_NAME
	--------------------------------------------------------------------------------
	ORIGINAL_NAME
	--------------------------------------------------------------------------------
	BIN$eVkR+F4mRhirdSo3qLPy0Q==$0
	TEST2

	SQL> FLASHBACK TABLE TEST1 TO BEFORE DROP;
	FLASHBACK TABLE TEST1 TO BEFORE DROP
	*
	ERROR at line 1:
	ORA-38305: object not in RECYCLE BIN

    case-2: to delete all tables from recyclebin:
    ---------------------------------------------
    syntax:
	PURGE RECYCLEBIN;

	SQL> PURGE RECYCLEBIN;
	Recyclebin purged.

	SQL> SELECT OBJECT_NAME, ORIGINAL_NAME FROM RECYCLEBIN;
	no rows selected

    case-3: to delete a table from database permanently:
    ----------------------------------------------------
    syntax:
	DROP TABLE <TABLE NAME> PURGE;


	SQL> CREATE TABLE TT1 (SNO INT);
	Table created	

	SQL> SELECT * FROM TAB;
	TNAME
	--------------------------------------------------------------------------------
	TABTYPE        CLUSTERID
	------------- ----------
	TT1
	TABLE

	SQL> DROP TABLE TT1 PURGE;
	Table dropped.

	SQL> SELECT OBJECT_NAME, ORIGINAL_NAME FROM RECYCLEBIN;
	no rows selected

	SQL> FLASHBACK TABLE TT1 TO BEFORE DROP;
	FLASHBACK TABLE TT1 TO BEFORE DROP
	*
	ERROR at line 1:
	ORA-38305: object not in RECYCLE BIN
