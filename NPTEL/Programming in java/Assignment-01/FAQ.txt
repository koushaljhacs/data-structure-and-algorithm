FAQ-01: What is a platform?

A platform is the hardware or software environment in which a program runs. Most platforms can be described as a      combination of the operating system and hardware, like Windows 2000/XP, Linux, Solaris and MacOS.

FAQ-02: Why Java is platform independent?

Platform independence means that execution of your program does not dependent on type of operating system(it could be any : Linux, windows, Mac, etc.). So compile code only once and run it on any System. This is in contrast to programming in C/C++, where you need to compile the code for every machine on which you want to run it. Java is both compiler (a program in Java language (i.e. .java file), is compile (using javac) and interpreter (using Java Virtual Machine (JVM)) based language. Your java source code is first compiled into byte code using javac compiler. This byte code can be easily converted to equivalent machine code using JVM. JVM is available in all operating systems we install. Hence, byte code generated by javac is universal and can be converted to machine code on any operating system, this is the reason why java is platform independent.

FAQ-03: what is JVM

JVM is an acronym for Java Virtual Machine. It is called a virtual machine because it doesn't physically exist. In java programming environment, programmer writes his program (as .java file), the Java compiler translates the program into byte code (i.e., .class file) and finally it is executed. Note that this bye code is in accordance to the sub systems, memory organization, data types, and instructions of JVM architecture. This JVM, provides run-time environment and supports to load code, verifies code, and execute code.
