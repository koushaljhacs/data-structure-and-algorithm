4. ClosestElementSearch
You are given a sorted integer array arr and a target value target. Your task is to find the closest element to the target value in the array.

Input: A sorted integer array arr (non-empty, may contain duplicates)
       An integer target

Output: Return the closest element to the target
        If there are two elements with equal distance from the target, return the smaller element

Example-1:
    Input: arr = [1, 3, 5, 7, 9], target = 4
    Output: 3
    Explanation: 
        - Distance from 3: |3-4| = 1
        - Distance from 5: |5-4| = 1
        Both are equally close, so we return the smaller element (3)

Example-2:
    Input: arr = [2, 5, 8, 12, 16], target = 10
    Output: 8
    Explanation:
        - Distance from 8: |8-10| = 2
        - Distance from 12: |12-10| = 2
        Both are equally close, return smaller element (8)

Example-3:
    Input: arr = [1, 1, 2, 2, 2, 3, 3], target = 2
    Output: 2 (the element value)
    Explanation: 
        The closest element is 2 itself

Example-4:
    Input: arr = [1, 1, 3, 3, 3, 5, 5], target = 2
    Output: 1
    Explanation: 
        - Distance from 1: |1-2| = 1
        - Distance from 3: |3-2| = 1
        Both distances are equal, return smaller element (1)

Constraints:
    1 <= arr.length <= 10^5
    -10^9 <= arr[i] <= 10^9
    -10^9 <= target <= 10^9

Complexity Goals:
    Time Complexity: O(log n) is optimal
    Space Complexity: O(1)

Hints:
    - Think about using binary search since the array is sorted
    - Consider what happens when the target is between two elements
    - Remember the tie-breaking rule: when distances are equal, return the smaller element
    - Handle edge cases where target is outside the array bounds
